Haley's Recipe Book Website

Contents
--------
- index.html: open this file in Chrome, Edge, Firefox, or Safari.
- recipes.js: the recipe text and metadata.
- assets/: local recipe images.

Features
--------
- 96 recipes
- Full-text search across titles, tags, ingredients, and instructions
- Category filtering
- Tag filtering
- Image cards and a book-like recipe reader
- Original recipe links
- Works locally without installation or internet, except when opening source links

How to use
----------
1. Extract the ZIP file.
2. Open the extracted folder.
3. Double-click index.html.
4. Keep index.html, recipes.js, and the assets folder together.

You can also print an open recipe from the browser.
